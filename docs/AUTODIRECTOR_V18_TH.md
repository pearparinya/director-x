# AutoDirector v18 — DIRECTOR X 2.17

เมนู `AutoDirector v18 • ภาพ Gemini / วิดีโอ Flow` สร้างเรื่องใหม่โดยสุ่มหนึ่งในห้าหมวดเดิม สุ่มพล็อตเมื่อเว้นแนวคิดว่าง ใช้ MASTER หลักสามคนและตัวละครเสริมที่ลงทะเบียน ทุกคนเป็นตัวละครสมมติผู้ใหญ่ บทภายในยังใช้ชื่อและรหัสเดิมเพื่อไม่ให้จับคู่ภาพผิด

Phase 1 เรียก API เขียนเฉพาะโครงเรื่องแล้วหยุดที่สถานะ `awaiting_outline` กดงานเขียนบทหรือ Phase 1 เพื่ออ่านชื่อช่อง หมวด ชื่อเรื่อง คำโปรย เรื่องย่อและรายชื่อตอน กดยืนยันก่อนเริ่มเขียนบท 24 ฉาก/EP โดยบันทึกช่วงงานไว้ทำต่อได้ แอปเตรียมบทภายในหลังยืนยัน จากนั้นเลือกเปิดคำสั่งทีละขั้น ไม่สร้างภาพหรือวิดีโอเอง

Phase 2–4 เลือก EP แล้วเปิดภาพ Gemini → บทพูด → XML ตามลำดับ ต้องเปิดโครงเรื่องก่อน ความคืบหน้าเมนูแยกต่อเรื่อง/ฉบับบท/EP เป็นเพียงการเปิดคำสั่ง ไม่ใช่สถานะสร้างสื่อสำเร็จ ภาพปกรวม 9:16 และ 16:9 ใช้สามคน ปกตอนใช้ 1–2 คน ภาพฉากไม่มีข้อความ กำหนดตัวละครและตำแหน่งครบ เสื้อผ้าสี่ส่วน Top / Bottom / Shoes / Accessories ต้องมีค่าก่อนช่วงบทผ่านตรวจ

ZIP เดิมมีชุด `AUTODIRECTOR/` เพิ่มสำหรับเรื่องในโหมดนี้:

- `01_OUTLINE.txt`
- `02_COVER_STORY_GEMINI.txt`
- `EPxx_IMAGES_GEMINI.txt`
- `EPxx_DIALOGUE.txt`
- `EPxx_FLOW.xml`

The Man = GAWIN, Woman 1 = RINLADA, Woman 2 = MIND; ตัวเสริมใช้ Supporting พร้อมรหัส MASTER ของตัวเอง คำสั่งภาพ/วิดีโอใช้ชื่ออ้างอิงนี้ ส่วนคำพูดไทยและข้อความปกคงต้นฉบับ รูปจริงใน MASTERS และ BACKUP/story.json เก็บเดิม ไฟล์ชุดเดิมยังอยู่เพื่อความเข้ากันได้ ให้ใช้ AUTODIRECTOR สำหรับขั้นตอนใหม่

XML เป็นเอกสารจัดบท ไม่ใช่รูปแบบนำเข้าหรือ API ที่ Flow รับรอง ให้คัดลอก motion_prompt ของฉากนั้นไป Flow และแนบภาพฉากที่ตรวจแล้ว มี dialogue, lighting, typography_safe_zone และสถานะ template_requires_frame_review เสมอ ไม่อ้างว่าภาพผ่านตรวจจากการดาวน์โหลดไฟล์ ต้องนำภาพ Gemini กลับแอป เทียบ MASTER และยืนยันก่อนเปิดคำสั่งวิดีโอพร้อมใช้ เมนูวิดีโอพร้อมใช้ยังตรวจ fingerprint ของภาพ บท และ MASTER เดิม

ใช้ภาพต้นฉบับเป็นหลักสำหรับหน้า ผม สีผม รูปร่างและสัดส่วน ไม่เพิ่มขนาดอวัยวะหรือเปลี่ยนสีผิวเพื่อทำตามคำคุณศัพท์ เสื้อผ้าเป็นแฟชั่นเข้ารูปตามฉากสำหรับผู้ใหญ่ มีการปกปิดและไม่โปร่งใส แสงขาวสว่าง 5500K ไม่ติดเหลือง ปกรูปครึ่งตัว ตัวอักษรกลุ่มเดียวกลางล่าง เป้าหมายความเหมือนต้องตรวจจากผลจริง ไม่มีการรับประกัน 100% จากคำสั่ง

เรื่องเก่าคงโหมดเดิม ไม่แปลงบทหรือเขียนทับอัตโนมัติ การทดสอบโค้ด/CI ไม่ใช่การรับรองผลสร้างภาพ Gemini หรือวิดีโอ Flow บนบัญชีจริง


## 2.18 — Gemini NEXT

เมนู AutoDirector เพิ่ม `คัดลอกทั้งหมด • Gemini next` เลือกทั้งเรื่องหรือเฉพาะ EP ได้ เรื่องที่สร้างในโหมด AutoDirector 2.17 ใช้ได้ทันที ไม่ต้องเขียนบทใหม่ Phase 2 ราย EP ก็ใช้ชุด NEXT เช่นกัน ใน ZIP มี `AUTODIRECTOR/ALL_GEMINI_NEXT.txt` และ `EPxx_GEMINI_NEXT.txt` เพิ่ม

แนบ MASTER ตามรายชื่อพร้อมคำสั่งครั้งแรก Gemini ได้รับคิวชัดเจน: ปกรวมแนวตั้ง/แนวนอน → ปก EP แนวตั้ง/แนวนอน → ทุกฉากตามลำดับ แล้วทำ EP ถัดไป (ทั้งเรื่อง) หนึ่ง EP 24 ฉากรวมปกรวม = 28 ภาพ สอง EP = 54 ภาพ ไม่มีการตัดทอนฉาก สถานะและรหัสภาพแสดงนอกภาพ ฉากใช้ EPxx_SCxxx สำหรับจับคู่เมื่อนำภาพกลับแอป

สั่งสร้างภาพแรกแล้วหยุดรอ `next` หรือ `ถัดไป` ทีละภาพ มี `retry` / `แก้ภาพ` และ `ไปที่ รหัสภาพ` ไม่ขยับคิวเมื่อเกิดข้อผิดพลาดหรือโควตาเต็ม ต้องขอภาพต้นฉบับหากข้อมูลอ้างอิงหาย ไม่สมมติว่าจำข้ามแชตได้ หลังภาพสุดท้ายไม่วนกลับ

นี่คือคำสั่งควบคุมการสนทนาใน Gemini ไม่ใช่การควบคุมบัญชี Gemini หรือปุ่ม native จาก DIRECTOR X ไม่ตรวจยืนยันว่าบริการภายนอกสร้างภาพสำเร็จแล้ว หากข้อความยาวเกินช่องแชตให้แนบไฟล์ TXT พร้อม MASTER แล้วสั่งอ่านไฟล์และเริ่มคิว; หากบริบทไม่พอให้ใช้ราย EP และทำต่อด้วยรหัสภาพ คำสั่งไม่รับประกันว่าบริการภายนอกทำตามได้ทุกครั้ง
